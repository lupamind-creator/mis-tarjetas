# Mis Tarjetas

App Android para controlar tus tarjetas de crédito: gastos, fechas de corte y de pago, compras a meses sin intereses, calendario y avisos antes de cada pago.

## Descargar

Última versión: **https://github.com/jcastanedaalferez-ship-it/mis-tarjetas/releases/latest/download/MisTarjetas.apk**

1. Abre ese enlace en tu celular y descarga el archivo.
2. Ábrelo. Si Android lo pide, permite *instalar apps de origen desconocido* para Chrome o tu navegador.
3. Al abrir la app, acepta las notificaciones para recibir los recordatorios de pago.

Para actualizar, instala el APK nuevo encima; tus datos se conservan.

## Cómo funciona

- Tus datos se guardan solo en tu teléfono. Haz un respaldo en *Tarjetas → Copiar respaldo*.
- Cada vez que se sube un cambio a `main`, GitHub compila el APK y lo publica en *Releases*.
- El código de la app está en `www/index.html`. Se empaqueta con [Capacitor](https://capacitorjs.com).
